# OmniIsle — native Forge 1.20.1 port (work in progress)

This repository is being used to develop a **native Forge 1.20.1** version of [OmniIsle](https://modrinth.com/mod/omniisle), originally by Hack337. It is not a completed or verified port.

Port target: Forge 47.3.0, Java 17. No Sinytra Connector or Fabric runtime.

Upstream project: https://github.com/y9hack337/OmniIsle (GPL-3.0). Do not redistribute a release until the licensing discrepancy with the 1.20.1 JAR metadata is resolved.
